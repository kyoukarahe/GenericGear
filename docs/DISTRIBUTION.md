# Source and binary distribution

The first candidate is source-only. The complete selected C#/TypeScript source,
build inputs, lockfiles, example generators, tests and instructions are here.
Local generated DLLs, PDBs, nupkgs, JS bundles and Unity players are not release
assets. Do not relabel old private archives as this version.

Before offering any binary, identify the precise source snapshot and actual
build/installation scripts needed for that binary, include upstream notices,
audit embedded paths/maps and provide Corresponding Source through an applicable
AGPL section 6 method. A generic repository homepage or unrelated future branch
is not a substitute for that source. No private report may be a required build
input. This source-only decision avoids claiming closure for unpublished Unity
runtime bundles, trimming, IL2CPP or externally supplied proprietary assets.

Distribution and network deployment are separate questions. Shipping modified
or combined covered work may create source/notice obligations; AGPL section 13
also addresses remote interaction with modified versions. Merely returning
generated data, or calling something an API, does not settle the combined-work
question. Linking a library, serving browser JS, a Unity executable, and a
separate server process each need their own analysis. Do not assume all network
software must be relicensed, or that every HTTP boundary avoids obligations.
The actual [AGPL text](https://www.gnu.org/licenses/agpl-3.0.html), not this
summary, governs. Seek legal advice for the deployment in question.

An AGPL-compatible .NET runtime/third-party distribution is not an automatic
Unity legal-compatibility finding. No linking exception has been added. Unity
engine/UPM/player redistribution is held pending review of the actual components,
Unity terms and intended use. Commercial first-party permission cannot waive
Unity or other third-party terms.
